# AIDE-Pro
AIDE Pro 是 Android 设备上一款**强大的集成开发环境（IDE）**，主要用于**直接在手机或平板上编写、编译和运行 Java 程序**，也支持 Android 应用开发。

---

## 📱 AIDE Pro 核心特点

| 功能 | 说明 |
|------|------|
| **Java 编程** | 支持在手机上写 Java 控制台程序、Android 应用 |
| **实时编译** | 边写代码边编译，实时看到效果 |
| **代码补全** | 智能提示，提高编码效率 |
| **内置教程** | 提供 Java 和 Android 开发入门教程 |
| **Git 集成** | 支持克隆、提交、推送 GitHub 仓库 |
| **无广告** | Pro 版本去除了广告，体验更清爽 |

---

## 🎯 适合谁用

- **学生党**：没有电脑时也能练 Java
- **新手**：随时随地写代码，利用碎片时间
- **GitHub 用户**：手机端编辑代码、提交变更
